# Curso de HTML e CSS – Estudonauta

Este repositório reúne todos os exercícios, anotações e projetos práticos desenvolvidos durante o curso de **HTML5 e CSS3** oferecido pelo Estudonauta, ministrado por **Gustavo Guanabara**. O objetivo principal é consolidar os fundamentos da construção de páginas web estáticas e responsivas utilizando apenas HTML e CSS puros, com foco em boas práticas e organização profissional de código.

## Conteúdo Estudado

Ao longo do curso, estou estudando os seguintes tópicos:

- Estrutura básica de um documento HTML
- Utilização de tags semânticas para organização e acessibilidade
- Inserção e formatação de imagens, links, listas, tabelas e vídeos
- Aplicação de estilos com CSS: cores, fontes, espaçamentos e bordas
- Modelo de caixa (Box Model)
- Posicionamento de elementos: `display`, `float`, `position`
- Layouts com Flexbox
- Design responsivo utilizando Media Queries
- Organização de arquivos, separação de estilos e boas práticas de projeto

## Projetos Desenvolvidos

Durante o curso, desenvolvi os seguintes projetos como forma de aplicar na prática os conceitos aprendidos:

- **Site Android** – site institucional com múltiplas seções, imagens, links internos e layout adaptativo
- **Cordel Moderno** – página estilizada com efeito parallax e ênfase em formatação visual com CSS
- **Rede Social** – simulação de uma interface de rede social, com organização de conteúdo, imagens e layout fluido
- **Media Queries** – projeto voltado para aplicação de responsividade em diferentes tamanhos de tela
- **Fast Food** – cardápio de restaurante com layout moderno e design responsivo pensado para mobile e desktop

## Tecnologias e Ferramentas Utilizadas

- HTML5
- CSS3
- Visual Studio Code
- Extensões utilizadas: Live Server, Auto Rename Tag, Prettier, HTML CSS Support

## Objetivo Pessoal

Meu objetivo com este curso é construir uma base sólida no desenvolvimento front-end, dominando o HTML e o CSS para produzir interfaces limpas, bem estruturadas e responsivas. Esta etapa é essencial para avançar futuramente no uso de JavaScript, frameworks modernos e integração com APIs.
